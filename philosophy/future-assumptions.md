# 将来仮説 / Future assumptions v1.0.0

## この文書の読み方

以下は予測・設計仮説であり、確認済み事実ではない。根拠が新たに得られた場合は、調査記録を追加し、必要なら新しい版で更新する。

1. AIエージェントは、情報取得だけでなく、委任された目的のもとでサービスを探索・比較・依頼・実行する利用主体になる。
2. 人間向けGUIのみを前提とするサービスは、コスト、信頼性、アクセシビリティ、相互運用性の面で相対的な制約になる。
3. プロトコルは変化し続ける。持続的な価値は、目的・意味・委任・ポリシー・証跡・救済をプロトコルから独立して設計することにある。
4. 最大の難所はモデル能力だけではない。アイデンティティ、権限、責任、同意、経済的インセンティブ、規制、紛争処理がボトルネックになる。
5. Agent Readyは二値の認証ラベルではなく、能力・影響・可逆性ごとの成熟度として扱うべきである。

## 反証・見直しの兆候

- 人間の確認や責任主体が不可避な領域で、代理行為の価値が恒常的に実証されない。
- 共通の委任・責任モデルより閉じたプラットフォームが一貫して優位となり、移植性の便益が実証されない。
- セキュリティまたは規制コストが、多くの領域で自動化便益を恒常的に上回る。
- AIの直接利用より、改善された人間向けUIの方が実証的に低コストかつ安全である。
