# プロジェクト意図 v1.0.0

このリポジトリは、Agent Native Societyを、公開された原典・設計・研究・事業仮説・将来の実装履歴として育てるSSOTである。単なるMCPリポジトリ、標準提案、またはスタートアップの宣伝資料ではない。

成果物は次の層を混同せず、相互リンクする。

| 層 | 置き場所 | 問うこと |
|---|---|---|
| 思想 | `philosophy/`, `origins/` | 何を目指し、何を価値とするか |
| コンテキスト | `context/` | どの判断原則で協働するか |
| 調査 | `research/`, `prior-art/`, `landscape/` | 何が事実として確認できるか |
| 意思決定 | `decisions/` | 何を選び、なぜ選んだか |
| 仕様・設計 | `docs/`, `architecture/` | 何をどのように成立させるか |
| 実装 | `implementations/` | どの主張をどう検証したか |
| 履歴 | `history/`, Git tags | いつ、何が変化したか |
