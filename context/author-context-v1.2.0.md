# 作者コンテキスト v1.2.0 — 著者の存在を伝えるためのプル型方針

**Date:** 2026-09-04  
**Relationship to prior records:** [`author-context.md`](author-context.md) と [`author-context-v1.1.0.md`](author-context-v1.1.0.md) を置き換えない追加記録。配布と成果物の位置づけを明確化する。

## CEOによる目的の明確化

CEOがこの時点で表明した目的は、Agent Native Societyを通じて、第三者が「寺脇将大という人間がいる」と知り、必要に応じてその問いと思考を自発的に辿れる状態をつくることである。

成果物は、この目的のための証拠・入口・対話可能な形であり、成果物の量、完成度、収益、人気、または単体での価値を自己目的にしない。これは、正確な先行研究、反証に耐える実装、説明可能な記録を不要にするものではない。むしろ、著者の存在を伝える手段が信頼を損なわないための条件である。

## 現在の配布方針

- 当面は**プル型**とする。公開済みまたは今後公開する正確な成果物を、興味を持つ人が自発的に見つけ、問い合わせられる状態に保つ。
- 個別の勧誘、設計パートナーへの能動的な打診、営業、広告、報道・登壇の売り込み、協働募集のための能動的な配信は行わない。
- 外部からの問い合わせには、既存の権限境界と事実の範囲で応答できる。ただし契約、実データ、決済、法令準拠の主張、公開約束はCEOの明示的承認なしに行わない。
- ライセンスまたは第三者再利用の方針は、この記録では決定しない。法令遵守を前提に、必要になった時点でCEOが適切な専門的助言とともに判断するまで、再利用を積極的に促さない。

## 判断上の注意

プル型は、反応がなくても目的達成を保証しない。認知・理解・信頼が生じたことは、関連する第三者からの自発的な反応、再現、批評、または問い合わせなどの確認可能な事実と区別して扱う。
