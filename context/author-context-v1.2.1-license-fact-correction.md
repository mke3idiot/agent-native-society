# 作者コンテキスト v1.2.1 — ライセンス事実の訂正と取扱い境界

**Date:** 2026-09-04
**Relationship to v1.2.0:** [`author-context-v1.2.0.md`](author-context-v1.2.0.md) の「ライセンスまたは第三者再利用の方針は決定しない」という記述の前提を訂正する。プル型方針は維持する。

## 訂正された事実

リポジトリには [`LICENSE`](../LICENSE) があり、Creative Commons Attribution 4.0 Internationalの文面を含む。GitHub APIの分類表示が `NOASSERTION` であったことは、このファイルが存在しないことや、ライセンスが選択されていないことを意味しない。

## 境界

この訂正は、当該ライセンスがどのファイル、寄稿、第三者素材、コード、将来の成果物にどのように及ぶかを法的に判断するものではない。第三者への再利用説明や新たな素材・寄稿の受入れでは、ライセンス原文、権利帰属、出所、適用範囲を確認し、必要なら専門家へ相談する。

参照: [ADR-0016](../decisions/ADR-0016-japan-law-handling-gates.md)、[日本法の取扱い基準](../research/japan-law-handling-baseline-2026-09-04.md)。
