# Agent Native Society

AIを既存システムの「機能」として組み込むだけでなく、AIエージェント自身が、委任された権限と責任のもとでシステムや現実世界のサービスを利用する主体になる社会を考える、公開・版管理された原典です。

これはMCPのサンプル集でも、単発のスタートアップ案でもありません。MCP、API、A2A、UCPなどは、Agent Native Societyへの移行を可能にする技術的手段の一部です。規格が変わっても、構想はそれらから独立して評価・発展できるようにします。

概念の全体像、設計上の前提、先行事例、社会実装の論点は[英日共通の目次](README.md)から参照できます。
