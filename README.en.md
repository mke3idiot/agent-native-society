# Agent Native Society

This is a public, versioned source record for thinking about a society where AI agents themselves become accountable users of systems and real-world services under delegated authority—not merely features embedded within existing systems.

It is neither a collection of MCP examples nor a one-off startup pitch. MCP, APIs, A2A, UCP, and successors are technical means toward the transition; the thesis is deliberately independent of any one standard.

See the [shared index](README.md) for the conceptual framework, design premises, related work, and implementation questions.
