# Autonomous Council Runbook v0.3

**Date:** 2026-09-04  
**Relationship to v0.2:** Adds the time-bounded bootstrap cadence in ADR-0013. The weekly steady-state model in v0.2 remains the target state.

## Cadence

| Period | Council cadence | Transition |
|---|---|---|
| 2026-09-04 through 2026-09-10 JST | daily | the 2026-09-10 run changes the existing task to weekly |
| From 2026-09-11 JST | every Monday, 09:00 JST | steady state |

The daily bootstrap exists to expose missing records, weak handoffs, and inappropriate authority boundaries while they are inexpensive to correct. It is not a permanent entitlement to daily autonomous reasoning.

## Unchanged boundaries

The council reads the repository and GitHub state before analysis, reports through the CEO Office, and obeys the authority boundary in [v0.1](autonomous-council-runbook-v0.1.md). Durable effects remain subject to the [session-to-repository handoff protocol](session-to-repository-handoff-protocol-v0.1.md).
