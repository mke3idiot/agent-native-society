# Agent Native Society

> A versioned body of thought, research, and reference architecture for a society in which AI agents can safely use real-world services as accountable participants.

日本語: [README.ja.md](README.ja.md) · English: [README.en.md](README.en.md)

## Position

This repository is an authored, evolving public record—not an MCP sample, product announcement, or claim of priority. It frames a future in which AI is not merely embedded *inside* systems, but can act as a governed user of systems and real-world services. Protocols are replaceable means; the societal, institutional, and design questions are the subject.

## The conceptual hierarchy

```text
Agent Native Society                 the society sought
└── AI Optimization                  method for moving existing society and systems toward it
    └── Agent Ready                  a service/system state: safely usable by agents
        └── MCP / API / A2A / UCP…   current and future technical means
```

## Record integrity

Published origin documents are immutable in meaning. Corrections, extensions, and changes of view are added as new, dated, versioned files; they are not silent rewrites of prior records. See [VERSIONING.md](VERSIONING.md).
