# Evidence scorecard

**Purpose:** measure whether public work is becoming credible evidence of Masahiro Terawaki's ability to think, design, investigate, and build across the Agent Native Society thesis.

This is not a popularity scoreboard. Numbers without relevance or evidence are not a proxy for market value.

## Quarterly review template

| Dimension | Evidence to record | Current baseline | Next review |
|---|---|---|---|
| Original synthesis | versioned thesis, explicit evolution, accurate prior art | founding corpus published | 2026 Q4 |
| Technical execution | reproducible implementation, tests, threat model, external reproduction | implementation brief only | 2026 Q4 |
| Research quality | dated primary sources, corrections, useful negative findings | initial prior-art and signal records | 2026 Q4 |
| Real-world validation | named or anonymized interviews, assessments, pilots, measurable workflow outcome | none | 2026 Q4 |
| Relevant recognition | technical review, invitation, citation, contribution, independent adoption | none | 2026 Q4 |
| Reusable assets | assessment method, profile, library, case pattern used more than once | none | 2026 Q4 |

## Rules

- Record only verifiable evidence and link it.
- Separate output (published material) from outcome (independent use, paid work, adoption, review).
- A negative result is evidence if it falsifies a useful hypothesis.
- Do not optimize the scorecard by adding low-value artifacts or vanity metrics.
