# Agent Native Society Manifesto — v1.0.0

## 出発点

AIは人の横にある補助機能から、委任された目的のためにサービスを使う主体へ移行しつつある。この変化を、速さや自動化率だけで判断してはならない。誰のために、どの権限で、何を実行し、誰が説明・停止・救済できるのかを社会の設計として扱う必要がある。

## 私たちが目指すもの

Agent Native Societyとは、AIが人間を置き換える社会ではない。人、組織、公共機関、事業者、AIエージェントが、それぞれの責任と権限を可視化しながら協働できる社会である。

1. AIは、正当な委任なく行動しない。
2. サービスは、人間向け画面だけでなく、意味・制約・結果を機械にも理解可能な形で示す。
3. 自動化の深さは、影響・可逆性・不確実性に応じて選ぶ。
4. 同意、予算、個人情報、資格、責任は推測ではなく明示的に扱う。
5. 失敗時には、停止、取消、訂正、異議申立て、救済の経路を設計する。
6. 相互運用性は囲い込みのためではなく、選択可能性と健全な競争のために使う。
7. 現在の規格は重要だが恒久ではない。社会的原則を特定のプロトコルに従属させない。

## 実装への姿勢

AI最適化は、既存の人間中心システムを捨てることではない。Agent Readyな状態へ段階的に移行し、必要に応じて人の承認を残し、監査可能な境界を増やす営みである。

本書は先行性を主張しない。関連する研究、標準、実装を尊重して記録し、異なる見解や将来の訂正を版として残す。
