# Agent Native Society Manifesto — v1.0.0

## Starting point

AI is moving from an adjacent assistive feature toward an actor that uses services for delegated goals. This transition must not be evaluated only by speed or automation rate. We must design the societal terms: for whom an action is taken, under what authority, what happens, and who can explain, stop, and remedy it.

## What we seek

An Agent Native Society is not a society that replaces people with AI. It is one in which people, organizations, public institutions, providers, and AI agents can cooperate with legible authority and responsibility.

1. An agent does not act without legitimate delegation.
2. Services expose meaning, constraints, and outcomes to machines as well as people.
3. The degree of automation matches impact, reversibility, and uncertainty.
4. Consent, budgets, personal data, qualifications, and liability are explicit rather than inferred.
5. Failure paths include stopping, cancellation, correction, contest, and remedy.
6. Interoperability serves choice and healthy competition, not lock-in.
7. Current standards matter, but none is permanent; social principles must not depend on one protocol.

## Implementation posture

AI Optimization is not a call to discard human-centered systems. It is a staged path toward Agent Ready services, preserving human approvals where needed and building auditable boundaries.

This document makes no claim to be first or sole originator. It records related work, welcomes disagreement, and preserves future revisions as versions.
